        Prüfhinweise

          Die Analyse erfolgt ausschließlich lokal im Browser. Opake Tagwerte werden weder gespeichert, übertragen noch in Ergebnissen angezeigt. If-Match verwendet starke Vergleiche; ein syntaktisch schwacher Tag kann diese Bedingung deshalb nicht erfüllen. Die Prüfung ersetzt keinen Request gegen die echte Ressource.
